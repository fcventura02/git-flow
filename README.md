# Guia Interativo de Estudo – Git Flow

Este projeto é uma página interativa que explica e demonstra o funcionamento do **Git Flow**.  
O objetivo é servir como **material de estudo** e **referência rápida** para desenvolvedores que desejam aprender ou implementar o fluxo de trabalho Git Flow em seus projetos.

---

## 🚀 Tecnologias Utilizadas

- **React.js** – Estrutura para criação da interface interativa.  
- **Vite** – Ferramenta de build e desenvolvimento rápido.  
- **Tailwind CSS** – Estilização moderna, responsiva e com foco em clean design.  

---

## 📚 Conteúdo da Página

A página inclui:

1. **Explicação do Git Flow** – conceitos principais e motivação.  
2. **Diagramas interativos** – mostrando as branches (`main`, `develop`, `feature/*`, `release/*`, `hotfix/*`).  
3. **Lista de comandos do Git Flow** – com exemplos práticos.  
4. **Exemplos de projetos complexos** – para contextualizar o uso do Git Flow.  
5. **Padrões de commits** – com base no Conventional Commits.  
6. **Correção de conflitos no Git** – exemplos e passo a passo.  
7. **Exercícios práticos** – para fixar o aprendizado.  

---

## 🛠️ Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Rode o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse no navegador:
   ```
   http://localhost:5173
   ```
